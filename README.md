# AmanCare - صيدلية إلكترونية

موقع صيدلية إلكترونية عربي RTL بهوية طبية نظيفة، مبني كواجهة Static منظمة وسهلة التطوير.

## الفكرة

AmanCare واجهة صيدلية إلكترونية بسيطة تعرض المنتجات، تسمح بإضافتها إلى السلة، ثم إرسال الطلب عبر واتساب. التصميم يعتمد على ألوان طبية مناسبة: الأبيض، الأزرق الفاتح، الأخضر الصحي، ولمسات برتقالية للعروض فقط.

## المميزات الحالية

- واجهة عربية كاملة RTL.
- تصميم طبي نظيف ومريح للعين.
- Hero Section قوي بعمق بصري وحركة خفيفة.
- كروت منتجات Glassmorphism.
- فلترة المنتجات حسب التصنيف.
- سلة مشتريات محلية.
- إرسال الطلب عبر واتساب.
- لوحة إدارة بسيطة لإضافة وحذف المنتجات.
- حفظ المنتجات والسلة داخل LocalStorage.
- بدون npm وبدون Build.

## بنية الملفات

```txt
Amancare/
  index.html
  styles.css
  app.js
  js/
    config.js
    products.js
    helpers.js
    products-ui.js
    cart.js
    admin.js
    main.js
  README.md
  DEVELOPMENT_PLAN.md
```

## دور كل ملف

- `index.html`: هيكل الصفحة فقط.
- `styles.css`: جميع التنسيقات، الألوان، الحركة، والتجاوب.
- `js/config.js`: إعدادات عامة مثل رقم واتساب، العملة، وكلمة مرور الإدارة المؤقتة.
- `js/products.js`: المنتجات الافتراضية.
- `js/helpers.js`: دوال مساعدة للتخزين، المال، الرسائل، والثيم.
- `js/products-ui.js`: عرض المنتجات والفلاتر.
- `js/cart.js`: منطق السلة وإرسال واتساب.
- `js/admin.js`: لوحة الإدارة المحلية.
- `js/main.js`: تشغيل التطبيق وتجميع الحالة العامة.
- `DEVELOPMENT_PLAN.md`: خطة التطوير الكاملة للموقع.

> ملاحظة: ملف `app.js` في الجذر موجود كملف قديم/احتياطي، والاعتماد الحالي داخل الصفحة على ملفات مجلد `js/`.

## بيانات لوحة الإدارة

كلمة المرور الافتراضية:

```txt
admin12345
```

هذه كلمة مؤقتة فقط. في النسخة الإنتاجية يجب استخدام Firebase Authentication بدل كلمة مرور داخل الكود.

## تعديل رقم واتساب

افتح الملف:

```txt
js/config.js
```

وعدّل القيمة:

```js
whatsappPhone: '970000000000'
```

اكتب الرقم بصيغة دولية بدون علامة `+`.

## التشغيل المحلي

افتح ملف:

```txt
index.html
```

مباشرة في المتصفح.

## تفعيل GitHub Pages

1. افتح إعدادات المستودع.
2. ادخل إلى Pages.
3. اختر Branch: `main`.
4. اختر Folder: `/root`.
5. اضغط Save.

بعدها سيظهر رابط الموقع من GitHub Pages.

## خطة التطوير

تمت إضافة ملف مستقل:

```txt
DEVELOPMENT_PLAN.md
```

وفيه خطة تحويل الموقع من نسخة Static إلى صيدلية إلكترونية قابلة للإدارة عبر Firebase.

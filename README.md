# AmanCare - صيدلية إلكترونية

موقع صيدلية إلكترونية عربي RTL بهوية طبية نظيفة مستوحاة من أسلوب Hero Premium في الفيديو، مع الحفاظ على ألوان مناسبة للمجال الطبي: الأبيض، الأزرق الفاتح، الأخضر الصحي، ولمسات عروض محدودة.

## المميزات

- واجهة عربية كاملة RTL.
- تصميم طبي نظيف ومريح للعين.
- Hero Section قوي بعمق بصري وحركة خفيفة.
- كروت منتجات Glassmorphism.
- فلترة المنتجات حسب التصنيف.
- سلة مشتريات محلية.
- إرسال الطلب عبر واتساب.
- لوحة إدارة بسيطة لإضافة وحذف المنتجات.
- حفظ المنتجات والسلة داخل LocalStorage.
- بدون npm وبدون Build، يعمل مباشرة من ملف `index.html`.

## بيانات لوحة الإدارة

كلمة المرور الافتراضية:

```txt
admin12345
```

## تعديل رقم واتساب

افتح ملف `index.html` وابحث عن:

```js
const phone='970000000000';
```

ثم غيّره إلى رقم الصيدلية بصيغة دولية بدون علامة +.

## التشغيل المحلي

افتح ملف:

```txt
index.html
```

مباشرة في المتصفح.

## تفعيل GitHub Pages

1. افتح إعدادات المستودع.
2. ادخل إلى Pages.
3. اختر Branch: `main`.
4. اختر Folder: `/root`.
5. اضغط Save.

بعدها سيظهر رابط الموقع من GitHub Pages.

## ملاحظة تنفيذية

هذه نسخة Static مناسبة كبداية وعرض سريع. إذا أردت تحويلها لاحقًا إلى نسخة إنتاجية كاملة، الأفضل نقل البيانات إلى Firebase Firestore وإضافة لوحة إدارة حقيقية بتسجيل دخول وصلاحيات.
